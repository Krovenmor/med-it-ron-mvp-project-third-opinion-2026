# mis-demo API

Базовый адрес: `http://localhost:8081`. Общие соглашения и коды ответов — в [README](README.md).

Демо-замена МИС клиники. Справочные данные (пациенты, их прошлые визиты, демо-заключения) зашиты в сервис. Созданные записи хранятся в памяти и пропадают при перезапуске. Слоты и записи отдаются в часовом поясе клиники (UTC+3), прошлые визиты из справочных данных — в UTC.

| Метод и путь | Назначение | Потребитель |
|---|---|---|
| `GET /api/v1/patients/{id}/history` | Посещения и записи пациента | b2b-service, b2c-service |
| `GET /api/v1/slots` | Ближайшие свободные слоты | b2c-service |
| `POST /api/v1/appointments` | Запись на слот | b2c-service |
| `GET /api/v1/services` | Справочник услуг клиники | веб врача |
| `POST /demo/reports` | Отправить демо-заключения в b2b-service | демо-кнопка «Симулировать поступление из МИС» |
| `POST /demo/reset` | Удалить созданные записи | демо-кнопка «Сбросить демо» |

## История пациента

`GET /api/v1/patients/{id}/history`

```json
{
  "visits": [
    { "service_code": "THER-CONSULT", "service_name": "Приём терапевта", "visited_at": "2026-08-20T09:00:00Z" }
  ],
  "appointments": [
    {
      "id": "APT-0001",
      "patient_id": "P-IGOR",
      "service_code": "PULM-CONSULT",
      "service_name": "Консультация пульмонолога",
      "scheduled_at": "2026-10-05T09:00:00+03:00",
      "referral_id": "9f1c…"
    }
  ]
}
```

| Поле | Описание |
|---|---|
| `visits` | Прошедшие визиты; всегда массив |
| `appointments` | Записи; всегда массив |
| `appointments[].referral_id` | ID рекомендации, по которой сделана запись; нет у записей, сделанных мимо B2C |

Для неизвестного пациента — 200 с пустыми массивами.

## Свободные слоты

`GET /api/v1/slots?service_code={service_code}`

N ближайших свободных слотов начиная с текущего момента; N задаётся `SCHEDULE_SLOTS_COUNT` (по умолчанию 10). Слоты — по будням в 09:00, 11:00, 14:00 и 16:00 по времени клиники. Занятые пропускаются, поэтому в ответе всегда ровно N слотов.

```json
{
  "slots": [
    { "id": "PULM-CONSULT.202610051100", "service_code": "PULM-CONSULT", "starts_at": "2026-10-05T11:00:00+03:00" }
  ]
}
```

| Код | Когда |
|---|---|
| 200 | Слоты получены |
| 400 | Нет `service_code` |

## Запись на слот

`POST /api/v1/appointments`

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `patient_id` | string | да | ID пациента в МИС |
| `slot_id` | string | да | ID слота из `GET /api/v1/slots` |
| `service_name` | string | да | Название услуги для записи |
| `referral_id` | string | нет | ID рекомендации-направления; по нему B2C находит запись |

```json
{
  "patient_id": "P-IGOR",
  "slot_id": "PULM-CONSULT.202610051100",
  "service_name": "Консультация пульмонолога",
  "referral_id": "9f1c…"
}
```

Ответ — запись в том же виде, что в истории пациента.

| Код | Когда |
|---|---|
| 201 | Запись создана |
| 200 | Этот слот уже занят этим же пациентом по этой же рекомендации; в ответе существующая запись |
| 400 | Некорректный JSON; нет обязательного поля; `slot_id` не распознан, не рабочее время или в прошлом |
| 409 | Слот занят другим пациентом или по другой рекомендации |

## Справочник услуг клиники

`GET /api/v1/services?q={query}`

Поиск по названию и коду услуги без учёта регистра; без `q` – весь справочник. `description` – понятное пациенту описание, врач подставляет его как текст для пациента при добавлении исследования.

```json
{
  "services": [
    {
      "code": "MRI-BREAST",
      "name": "МРТ молочных желез с контрастированием",
      "description": "МРТ даст врачу более подробное изображение для точного плана."
    }
  ]
}
```

Ответ всегда 200; если ничего не найдено – пустой массив.

## Демо-заключения

`POST /demo/reports`

Отправляет в `POST b2b-service /api/v1/reports` четыре демо-заключения. Повторный вызов безопасен: b2b-service ответит 200 по уже принятым исследованиям.

| Пациент | ID | Исследование | Ожидаемая срочность (мок ai-service) |
|---|---|---|---|
| Анна Смирнова | `P-ANNA` | `MG-2026-0001`, маммография, BI-RADS 4 | `priority` |
| Игорь Петров | `P-IGOR` | `CT-2026-0002`, КТ, солидный очаг 9 мм | `priority` |
| Сергей Иванов | `P-SERGEY` | `DX-2026-0003`, рентгенография, пневмоторакс | `emergency` |
| Ольга Кузнецова | `P-OLGA` | `DX-2026-0004`, рентгенография, без патологии | `normal` |

```json
{
  "delivered": [
    { "study_id": "MG-2026-0001", "status": 201, "response": { "case_id": "6b9a5672-…", "status": "draft" } }
  ]
}
```

| Поле | Описание |
|---|---|
| `delivered[].status` | HTTP-код ответа b2b-service |
| `delivered[].response` | Тело ответа b2b-service как есть |
| `error` | Есть только при 502: почему отправка прервалась |

| Код | Когда |
|---|---|
| 200 | Все заключения отправлены (смотреть `delivered[].status`) |
| 502 | b2b-service недоступен; в `delivered` то, что успело уйти |

## Сброс демо

`POST /demo/reset` удаляет все созданные записи; справочные данные остаются. Ответ 204.
